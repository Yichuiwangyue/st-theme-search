# ST Theme Search 🔍

A SillyTavern extension that adds a **search box** to the UI theme selector,
so you can quickly find themes by name instead of scrolling through a long list.

## Installation

**Method 1 – ST Built-in (recommended)**
1. In SillyTavern, go to Extensions → Install extension
2. Paste this URL: https://github.com/Yichuiwangyue/st-theme-search
3. Click Install

**Method 2 – Manual**
1. Download this repo as ZIP (Code → Download ZIP)
2. Unzip into `SillyTavern/public/extensions/theme-search/`
3. Refresh SillyTavern

## Usage
Click the theme selector as usual — a search box now appears at the top of the list!
Type any keyword to filter themes instantly.
